===================
Task to Opportunity
===================

Create an opportunity from a task

Configuration
=============
\-

Usage
=====
On tasks there's a feature to create an opportunity:

1) Form view
- "Create an Opportunity" button

2) List view
- Select task and use "Action" dropdown and select "Create an Opportunity"
