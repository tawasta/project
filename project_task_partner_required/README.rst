=============================
Project Task Partner Required
=============================
This module makes the **Customer (partner_id)** field mandatory on the
Project Task form view.

It enforces the requirement at the **user interface level**, ensuring that
users must select a customer when creating or editing tasks via the form.

Configuration
=============

No configuration is required.

The module works immediately after installation.

Usage
=====
- Go to **Project → Tasks**
- Create or edit a task
- The *Customer* field is now mandatory

The form cannot be saved without selecting a customer.
