=================================================================
Project: Manual Code for Tasks: Get Default from Project Sequence
=================================================================

* Autofills the manual task code field from project sequence and task running number,
  resulting in e.g. P01234-1, depending on how project_sequence is configured
* Task code remains editable

Configuration
=============
* None needed

Usage
=====
* Just create a new task to have it get its code automatically
* Next task number can be viewed/edited in project form view if needed
