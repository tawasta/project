====================================================
Sale/Project: Project Name from Sale Order Line Text
====================================================

* When project gets created from SO, get project name automatically 
  from the sold product's SO line text

Configuration
=============
* Configure a product so that it creates a project+tasks when the
  the product is sold

Usage
=====
* Confirm a sale with the above product on an SO line.
* Created project is renamed according to the SO line text
